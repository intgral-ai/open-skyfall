# Roadmap

## First acceptance work

- Correct the relay case's terminal blades and missing mounting ear, with
  source-linked geometric checks. Keep the [failed fidelity audit](../cases/omron-g2r/MANUAL-AUDIT.md).
- Add a per-feature evidence record that separates observed dimensions,
  assumptions, missing geometry and contradictions.
- Replace speculative internal decomposition with supported physical parts or
  clearly labeled hypotheses.

## Native authoring

- Extend reviewed smlibpy authoring beyond one registered parameter edit.
- Preserve unique definitions and repeated occurrences in a nested native STEP
  product hierarchy, not only in the project document.
- Migrate the bounded legacy fitting path without weakening source accuracy.

## Host and evaluation

- Verify actual ChatGPT-host rendering and tool delivery in a supported account.
- Evaluate held-out, redistributable mechanical and industrial-design examples.
- Compare accepted output cost with whole-object LLM authoring and an eligible
  specialized checkpoint using the same evidence and acceptance gates.

No item here is a completed capability or a promised release date.
