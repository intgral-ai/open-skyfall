# Desk lamp decomposition example

The PNG is an independently authored illustration distributed under this repository's MIT license. The plan is an agent interpretation of that actual image. It uses
relative units, five separate concept parts and three subassemblies. The collar
is inferred; internal mechanisms are omitted. No reconstruction accuracy, native
CAD, engineering assembly or manufacturing readiness is claimed.

Run `open-skyfall --workspace jobs decompose examples/decomposition/desk-lamp.png --rights "Original MIT illustration" --plan examples/decomposition/plan.json`, then open `/?project=<returned-id>`.
